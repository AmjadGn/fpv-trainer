# Content Guidelines

## Terminology

| Use | Avoid |
|---|---|
| Free Flight | Open Match |
| Ranked Run | Ranked Game |
| Practice | Casual Match |
| Verified Result / Local Result | “Score upload” |
| Ghost / Replay | Demo tape |
| Training Module | Training Race |
| Season / Tournament / Mission / Division | Battle pass / loot |

## Buttons

Prefer specific actions:

- Practice
- Start Ranked Attempt
- Start Flight
- Continue as Guest

## Empty / error tone

Direct, calm, actionable. One relevant action maximum for empty states. Never shame guests.

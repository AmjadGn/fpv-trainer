# v1.3.0 Known Limitations — Expeditions Preview

Honest limitations for the public **FPV Simulator v1.3.0 — Expeditions Preview** release.

None of these are hidden; they are acceptable for a preview launch and deferred to later work (see the v1.4.0 backlog issue).

## Product / content

- Only **one** Expedition mission is available: Coastal Ruins Survey
- Coastal Ruins uses **proxy-quality, repository-owned art** — not final production art and not purchased art
- No additional Mediterranean subregions ship in this release
- No audio/environment polish beyond what already exists for the proxy location

## Online / accounts

- No cloud synchronization of mission results or Personal Bests
- No accounts for mission progress
- No online leaderboards for Expeditions
- No multiplayer

## Local data

- Mission history, Personal Bests, and presentation photos are **local to the browser/device**
- Clearing browser storage or using another device will not carry mission progress
- IndexedDB open failure degrades to **memory-only** mode and is reported truthfully (progress will not survive reload)

## Persistence / runtime (deferred technical)

- Full **cross-tab reactive synchronization** is deferred; same-tab durability is the supported path
- Presentation photo encoding may occasionally finish as **partial or unavailable**; core results remain valid
- **Replay clear-data key mismatch** remains deferred (`clearLocalProductData` vs live replay storage key)
- **Settlement-registry long-session cleanup** hardening remains deferred
- Outer session / result IDs still include **wall-clock infrastructure** (not a pure simulation-clock redesign)
- Broader accessibility and stress hardening remain deferred

## Quality scope deferred

- Deeper accessibility audit
- Full browser compatibility matrix
- Mobile/touch polish beyond current usable baseline
- Complete fault-injection matrix
- Performance-budget instrumentation for Expeditions

## Competitive / future product (not in v1.3.0)

- Replay mission events
- Mission ghosts
- Seasonal Expedition challenges
- Leaderboards / backend persistence — only in a future separately approved release

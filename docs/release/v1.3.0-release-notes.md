# FPV Simulator v1.3.0 — Expeditions Preview

**Version:** 1.3.0  
**Release title:** FPV Simulator v1.3.0 — Expeditions Preview  
**Tag:** `v1.3.0`

This is a public, usable release of the browser-based FPV Simulator. New Expedition content is an **Expeditions Preview** — playable and durable locally, but not a finished multi-location Expedition product and not final production art.

## Highlights

### Core simulator (retained)

- Free flight and training functionality remain available
- Factory aircraft and compiled Hangar / Drone Builder aircraft remain compatible with Expeditions
- Controllers, environments, courses, and local replay tooling from prior releases remain available

### Expeditions Preview

- **Fly → Expeditions** entry from the Fly hub
- **Mediterranean Expedition Region** location package
- **Coastal Ruins** playable area (Mediterranean-inspired proxy environment)
- **Coastal Ruins Survey** — a first playable Expedition mission featuring deterministic FPV photography objectives in a Mediterranean-inspired proxy environment
- Three sequential photography objectives (stone sea arch, ruined lookout, cliffside ruin)
- Photography HUD and framing guide
- Deterministic evidence capture and scoring (Evidence Schema `2.0.0`)
- Crash and out-of-bounds mission failure
- Session retry without reloading the location
- Local mission result history
- Local Personal Best comparison and retention
- Local Personal Best presentation photos (best-effort)
- IndexedDB persistence (`fpv-missions-v1`, persistence schema `1.0.0`)

## What this release is not

- Not cloud-synchronized
- Not account-backed for mission progress
- Not an online leaderboard or multiplayer product
- Not a multi-location Expedition catalog
- Not final / purchased production art for Coastal Ruins
- Not a claim of complete cross-tab reactive synchronization

## Known limitations

Honest limitations for this preview are documented in
[`v1.3.0-known-limitations.md`](./v1.3.0-known-limitations.md).

Major deferred items include:

- One Expedition mission only
- Proxy-quality repository-owned art
- Local-only mission data (browser/device scoped)
- Deferred full cross-tab reactive sync
- Deferred settlement-registry long-session cleanup hardening
- Deferred replay clear-data key mismatch fix
- Occasional partial/unavailable presentation photo encoding

## Persistence notes

- Database: `fpv-missions-v1` (IndexedDB version `1`)
- Persistence schema: `1.0.0`
- Evidence Schema: `2.0.0` (unchanged; scoring is independent of persistence)
- Failed IndexedDB open degrades to in-memory storage and is reported truthfully
- Images never affect score; image failure does not invalidate core results
